# OOP_Ainur
Разработка сайта для автосервиса

**Мой проект:** 
Реализовать сайт для автосервиса
Запись клиентов на выбранную услугу, свободные окна и к свободным мастерам, прайс листы с услугами и расчет примерной стоимости

**Представленные данные для анализа:**
rynok_avtoservisa.csv - данные об оказании услуг автосервисами за определенный год (реальные данные)
rost.csv - статистика роста выручки автосервисов после внедрения онлайн запили (сгенерированные данные)
vozrast_avto.csv - средний возраст автомобилей (сгенерированные данные)
zapis.csv - средние показатели записи в автосервисы той или иной формой (сгенерированные данные)
avtopark.csv - кол-во автомобилей в россии в зависимости от года (реальные данные)

**Анализ данных представлен в файле: 
data_analysis.ipynb**
